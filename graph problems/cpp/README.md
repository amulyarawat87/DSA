# Graph Problems - C++

This folder stores C++ solutions for graph problems.

## Structure

```text
cpp/
├── README.md
├── .gitkeep
└── <problem-name>.cpp
```

## Problem Index (Extensible)

Add one row per problem as you solve more.

| # | Problem | Difficulty | File | Status | Notes |
| --- | --- | --- | --- | --- | --- |
| 1 | Example: Number of Islands | Medium | number-of-islands.cpp | Planned | BFS/DFS |

## Naming Convention

- Use kebab-case file names.
- Pattern: `<problem-name>.cpp`

Examples:

- `number-of-islands.cpp`
- `course-schedule.cpp`
- `shortest-path-in-binary-matrix.cpp`

## How To Add New Problems

1. Create the C++ file in this folder.
2. Implement solution with clear function naming.
3. Update the Problem Index table.
4. Add short complexity notes in `Notes` (optional).

## Optional Standard Header

You may use this format at the top of each file:

```cpp
// Problem: <name>
// Approach: <BFS/DFS/Dijkstra/Union-Find/etc.>
// Time: O(...)
// Space: O(...)
```
