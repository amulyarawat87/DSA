# Graph Problems - Java

This folder stores Java solutions for graph problems.

## Structure

```text
java/
├── README.md
├── .gitkeep
└── <problem-name>.java
```

## Problem Index (Extensible)

Add one row per problem as you solve more.

| # | Problem | Difficulty | File | Status | Notes |
| --- | --- | --- | --- | --- | --- |
| 1 | Example: Number of Islands | Medium | number-of-islands.java | Planned | BFS/DFS |

## Naming Convention

- Use kebab-case file names.
- Pattern: `<problem-name>.java`

Examples:

- `number-of-islands.java`
- `course-schedule.java`
- `shortest-path-in-binary-matrix.java`

## How To Add New Problems

1. Create the Java file in this folder.
2. Implement solution with clear method naming.
3. Update the Problem Index table.
4. Add short complexity notes in `Notes` (optional).

## Optional Standard Header

You may use this format at the top of each file:

```java
// Problem: <name>
// Approach: <BFS/DFS/Dijkstra/Union-Find/etc.>
// Time: O(...)
// Space: O(...)
```
